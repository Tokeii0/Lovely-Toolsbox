# CTF工具箱

一个用于管理和组织各种CTF工具的图形界面程序。

## 功能特点

- 工具导入和管理
- 分类系统
- 现代化图形界面
- 工具配置管理
- 搜索和过滤功能
- 系统托盘支持
- 自定义标题栏
- 最小化到托盘

## 安装说明

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 运行程序：
```bash
python main.py
```

## 目录结构

```
CTFTOOLS/
├── requirements.txt    # 项目依赖
├── main.py            # 主程序入口
├── src/               # 源代码目录
│   ├── ui/           # 界面相关代码
│   ├── core/         # 核心功能代码
│   └── utils/        # 工具函数
├── config/           # 配置文件目录
├── res/              # 资源文件目录
└── tools/            # 工具存储目录
```

## 使用说明

1. 启动程序后，可以通过界面导入新的工具
2. 为工具设置分类和描述信息
3. 使用搜索功能快速找到所需工具
4. 可以保存和导出工具配置
5. 最小化窗口时程序会自动缩小到系统托盘
6. 双击托盘图标可以快速显示主窗口
7. 右键托盘图标可以进行显示/退出等操作

## 界面特点

- 现代化的无边框窗口设计
- 自定义标题栏带图标
- 最小窗口尺寸：460x700
- 深色主题
- 系统托盘集成

## 开发环境

- Python 3.8+
- PySide6
- Windows/Linux
